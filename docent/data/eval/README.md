# 평가 질문 세트 (FE3 작성, BE1 사용)

`questions.csv`에 [역할 가이드 7장](../../docs/역할_가이드.md)의 "평가 질문 세트 30개"를 채웁니다. 정답이 CSV에 있는 질문 20개와 CSV에 없는 질문 10개입니다.

| 열 | 내용 |
| --- | --- |
| `question_id` | `Q01`처럼 고유한 번호 |
| `question` | 관람객이 할 법한 영어 질문 |
| `artwork_id` | 그 질문을 할 때 보고 있는 작품 |
| `answer_in_csv` | 정답이 콘텐츠 CSV에 있으면 `yes`, 없으면 `no` |
| `expected_answer` | `yes`면 기대하는 답의 핵심, `no`면 "확실하지 않다고 답해야 함" |
| `source_column` | 정답이 들어 있는 CSV와 열 (예: `artworks.csv:key_facts`) |

BE1은 프롬프트를 바꿀 때마다 같은 질문 세트로 전후를 비교합니다. `answer_in_csv=no`인 질문에 사실을 지어내 답하면 실패입니다.

# 인식 시험 사진 정답표 (BE2)

시험 사진 파일은 `data/test_photos/`에 두고 **git에 올리지 않습니다**(관람객 얼굴, 사진 저작권). 정답표 `recognition_answers.csv`만 커밋합니다.

## 파일 이름 규칙 → 정답표 자동 작성

사진을 저장할 때 이름을 `작품__조건__번호.jpg`(밑줄 두 개)로 붙이면, 나머지 칸은 도구가 채웁니다.

| 부분 | 쓰는 것 | 예 |
| --- | --- | --- |
| 작품 | e뮤지엄 ID(`PS…`) 또는 제목 일부. 기준 DB에 없는 그림이면 `none` | `씨름`, `PS0100100100100650400022`, `none` |
| 조건 | 사진 종류 | `web-gallery`(전시장 사진), `web-angle`(비스듬히), `web-glare`(반사), `web-crowd`(사람 가림), `poster` |
| 번호 | 같은 작품·조건의 몇 번째 사진 | `01` |

```bash
uv run python -m tools.make_answer_sheet
```

- 제목이 여러 작품에 걸리면(예: `단원 풍속도첩` → 화첩 25장) `artwork_id`가 `CHECK`가 되고 후보가 `note`에 적힙니다. 그 줄만 직접 고칩니다.
- 이미 표에 있는 사진은 그대로 두고 새 사진만 추가합니다.
- 인식 결과로 정답을 채우지 않습니다. 정답은 사진을 받은 사람이 아는 정보여야 시험이 됩니다.

## 인터넷에서 사진을 모을 때

- **박물관 공식 이미지와 같은 사진은 시험이 되지 않습니다.** 기준 DB가 바로 그 이미지라 무조건 맞힙니다. 전시장에서 관람객이 찍은 사진(블로그, 리뷰 등)처럼 각도·조명·유리 반사·액자가 보이는 사진을 고릅니다. 기준 이미지와 같은 파일이면 도구가 `note`에 표시합니다.
- 사진 주소는 `source_url`에 적어 둡니다. 남의 사진이라 팀 내부 시험에만 쓰고 공유·발표에 쓰지 않습니다.
- 다른 사람 얼굴이 크게 나온 사진은 피합니다.
- `none` 사진(기준 DB에 없는 그림, 포스터, 벽 등)도 몇 장 넣어야 "모르면 unknown"이 잘 되는지 잴 수 있습니다.

| 열 | 내용 |
| --- | --- |
| `photo_file` | `data/test_photos/` 안의 파일 이름 |
| `artwork_id` | 정답 작품의 e뮤지엄 ID, 기준 DB에 없으면 `none`, 확인 필요하면 `CHECK` |
| `condition` | 사진 종류(파일 이름에서 읽음) |
| `source_url` | 사진을 받은 주소 |
| `collected_by`, `collected_at` | 모은 사람, 날짜 |
| `note` | 도구가 남긴 확인 메모 |
