# 대화 시나리오 (FE3)

담당: FE3. [역할 가이드 7장](../../docs/역할_가이드.md)의 11/12–11/18 "대화 시나리오 5개"를 여기에 둡니다.

시나리오 하나에 파일 하나(예: `01_france_impressionism.md`)로 쓰고, 다음을 적습니다.
- 관람객 설정: 출신 국가, 익숙한 미술, 원하는 설명 길이
- 관람 순서: 어떤 작품을 어떤 순서로 보는지
- 이상적인 대화 예시: 관람객의 말과 도슨트의 답
- 꼭 들어가야 할 것과 하면 안 되는 말

BE1이 이 시나리오로 프롬프트(`server/prompts.py`)를 시험합니다.
