# AI 도슨트 작업 지침

`docent/`는 ArtBridge와 별개인 AI 도슨트 프로젝트다. 목표, 범위, 일정은 [`AI_도슨트_개발계획서.md`](AI_도슨트_개발계획서.md)를 따른다. 루트 `AGENTS.md`의 ArtBridge MVP 범위 제한(스마트글라스·음성·대화 생성 제외)은 이 폴더에 적용하지 않는다.

- ArtBridge 파일(`../src/`, `../data/`, `../app.py` 등)은 수정하지 않고, 코드를 공유하거나 결합하지 않는다. AI 도슨트 파일은 모두 `docent/` 아래에 둔다.
- Gemini API 키는 환경 변수나 `.env`에만 두고 커밋하지 않는다. 클라이언트 코드에 키를 넣지 않는다.
- 카메라 프레임과 음성은 처리에만 사용하고 기본적으로 저장하지 않는다. 세션 메모리는 세션이 끝나면 폐기한다.
- 작품 사실 정보는 콘텐츠 DB의 출처 있는 근거만 사용한다. 확인할 수 없으면 추정하지 말고 "확인 필요"로 기록한다.
- 외국 회화 비교를 영향 관계나 계보로 단정하지 않는다. 유사점과 차이점을 함께 설명한다.
- 이미지를 표시하거나 임베딩에 쓰면 작품별 이용 조건, 출처 URL, 확인일, 크레딧을 기록한다.
- 모델명과 SDK 버전은 공식 문서로 확인한 값을 기록한다.
