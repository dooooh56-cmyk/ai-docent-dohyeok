# ArtBridge 작업 지침

## 프로젝트 목적

> **2026-10-31 방향 변경 (사용자 결정)**: ArtBridge는 AI 도슨트(`../docent/`)의 추가 기능으로 관리하며, 수집 대상을 조선 회화와 비교용 해외 회화(일본 판화 포함)로 넓힌다. 수집은 기관 전체 메타데이터 → `data/classify_rules.csv` 쿼리 분류 → 분류된 작품 중 기관이 공개 라이선스로 표기한 이미지만 다운로드 순서로 진행한다. 기관의 작품별 공개 라이선스 표기(Met `isPublicDomain=true`, Smithsonian CC0, 공공누리 제1유형)는 사용자가 일괄 승인했으며 `license_log.csv`의 `rights_approved_by`에 규칙으로 기록한다. 기존 불교 조각 45점 카탈로그와 아래 계획은 유지하되, 회화 기준의 목표·평가는 별도로 갱신이 필요하다.

ArtBridge는 한국 불교 조각을 입력받아 중국·일본·인도/간다라의 유사 작품을 찾고, 이미지 유사도와 확인 가능한 메타데이터를 나란히 보여주는 개인 프로젝트다. 상세 목표, 데이터 기준, 6주 일정, 모듈 명세는 [`ArtBridge_프로젝트_계획서.md`](ArtBridge_프로젝트_계획서.md)를 따른다.

모듈별 상태, 선행 관계, 산출물, 완료 기준은 [`module-management.md`](module-management.md)를 기준으로 관리한다. 이 상태표는 실제 파일과 확인 결과에 맞춰 갱신한다.

이 프로젝트는 AI 도슨트와 별개로 유지한다. AI 도슨트 소스 자료는 기술적 배경으로만 참고하며, AI 도슨트의 앱·API·데이터·운영 구조를 ArtBridge에 가져오거나 수정하지 않는다.

## MVP 동작

- 한국 작품 카탈로그에서 선택하거나, 권리가 확인된 작품 이미지 파일을 질의로 받는다. 질의 업로드 파일은 기본적으로 저장하지 않는다.
- DINOv2와 CLIP의 사전학습 이미지 임베딩을 비교하고, L2 정규화한 뒤 코사인 유사도로 해외 작품 전체 Top-5를 반환한다. 사용자가 요청하면 중국·일본·인도/간다라 권역별 필터를 적용한다.
- 시대·재료·도상·자세 등 메타데이터는 이미지 유사도와 별도로 비교해 표시한다. 검증된 실험 없이 메타데이터 가중치를 추천 순위에 섞지 않는다.
- 결과에는 작품명, 권역, 모델 내 상대 점수, 비교 메타데이터, 공식 소장품 페이지와 필요한 이미지 크레딧을 연결한다. 점수를 역사적 영향·계보·동일성의 증거처럼 설명하지 않는다.
- 초기는 20점(권역별 5점)으로 시작하고, 120점(한국·중국·일본·인도/간다라 각 30점)을 목표로 한다. 실제 수량과 권역별 편차를 그대로 기록하며 데이터 규모를 대표성으로 과장하지 않는다.

## 범위 경계

MVP에는 카탈로그·권리 검증, 이미지 임베딩, 코사인 검색, 메타데이터 비교, 평가, 로컬 데모만 구현한다. 스마트글라스, 시선/객체 추적, 음성 입력·출력, RAG 설명 생성, 파인튜닝, 공개 서비스와 계정·클라우드 기능은 구현하지 않는다. 120점 규모는 NumPy 기반 완전탐색으로 처리하고, 측정된 규모·속도 문제가 생기기 전에는 FAISS나 별도 벡터 DB를 추가하지 않는다.

## 자료와 이미지 권리

- 상위 지침을 따른다. `sources/` 안의 모든 자료는 읽기 전용이며 수정·이동·이름 변경·삭제하지 않는다. 동기화된 AI 도슨트 파일을 ArtBridge 산출물로 취급하지 않는다.
- 작품 메타데이터와 이미지 권리는 작품별로 확인한다. 공식 박물관 작품 페이지와 해당 기관의 이용 정책을 우선 사용하고, 이미지가 웹에 공개되어 있다는 이유만으로 다운로드·저장·임베딩·재배포 허용으로 간주하지 않는다.
- `rights_status`, 라이선스 원문 URL, 확인 날짜, 크레딧을 기록한다. 권리 상태가 불명확하거나 필요한 허가가 확인되지 않은 이미지는 수집·임베딩·데모에 사용하지 않는다.
- 기관별 API·다운로드·비상업 조건을 준수한다. 공개 데모·출판·상업 사용을 시작하기 전에는 그 용도에 맞는 권리를 다시 확인한다.
- 기관 원문 표기와 정규화·번역 필드를 분리한다. 미확인 값을 추정해 채우지 말고 결측 또는 불확실성으로 표시한다.

## 데이터와 코드 구조

작품은 `artwork_id`로 연결한다. 카탈로그에는 원문/번역 작품명, 권역, 원문/정규화 시대, 재질, 도상·자세, 박물관·소장번호, 작품 페이지, 이미지 경로·출처·크레딧·라이선스, 권리 확인일, 파일 해시, `image_view_id`, `split_group_id`를 계획서에 정의된 기준으로 보관한다.

- `src/catalog.py`: `load_catalog`, `validate_catalog`, `usable_image_rows`로 카탈로그를 읽고 검증하며, 사람의 권리 확인 상태를 용도별 사용 게이트로 적용한다. 자동으로 저작권을 판정하지 않는다.
- `src/embed.py`: `load_image`, `embed_image`, `embed_catalog`, `save_embeddings`로 입력 이미지를 모델 벡터로 바꾸고, 벡터와 작품 ID·모델·전처리·데이터 버전을 함께 저장한다.
- `src/search.py`: `normalize_vectors`, `cosine_top_k`, `recommend_cross_region`로 벡터를 정규화하고 해외 후보 검색을 수행한다. 한국 외 입력, 같은 작품 ID/그룹, 빈 결과와 잘못된 벡터를 명시적으로 처리한다.
- `src/compare_metadata.py`: `compare_metadata`로 질의·후보의 시대, 재질, 도상, 자세 등 확인된 값을 병렬 비교한다. 결측과 표기 차이를 숨기지 않고 순위 점수는 계산하지 않는다.
- `src/evaluate.py`: `precision_at_k`, `recall_at_k`, `ndcg_at_k`, `check_query_gallery_leakage`로 사람 라벨 기반 검색 품질과 평가 누수를 점검한다.
- `app.py`: `get_query_image`, `run_recommendation`, `render_results`로 입력, 결과 조합, 결과 카드 표시를 맡는다. 데이터 처리와 모델 로직을 UI 안에 중복 구현하지 않는다.

한 함수는 한 가지 책임을 맡고, 경로·모델 식별자·Top-k 등은 호출 인자나 설정으로 전달한다. 작은 카탈로그에 불필요한 추상화, 서비스 계층, 데이터베이스, 캐시, 복잡한 설정 체계를 미리 만들지 않는다. 구조를 바꾸면 계획서의 모듈 명세도 함께 고친다.

## 평가와 누수 방지

- DINOv2와 CLIP은 같은 데이터 버전, 질의 집합, 전처리 조건에서 비교한다. 모델명·체크포인트·라이브러리 버전·임베딩 차원·전처리·데이터 버전을 결과와 함께 남긴다. 서로 다른 모델의 코사인 점수를 확률처럼 비교하지 않는다.
- Precision@5, Recall@5, nDCG@5와 권역별 결과 분포를 보고하고, 작은 표본의 지표는 정성 검토와 표본 수를 함께 제시한다.
- 동일 작품의 다른 각도·복제 레코드·같은 이미지의 크롭/리사이즈는 같은 `split_group_id`로 묶는다. 질의와 갤러리에 동일 객체나 이미지 해시가 동시에 들어가지 않도록 한다.
- 관련성 라벨을 본 뒤 반복 조정한 결과를 최종 일반화 성능으로 주장하지 않는다. 평가 질의와 사람 판정 기준을 고정해 버전으로 남긴다.

## 작업 원칙

- 작업 전 계획서와 이 파일을 확인하고, 기존 저장소에 이미 있는 코드·데이터 구조를 먼저 살핀다.
- ArtBridge는 AI 도슨트 저장소 안에서 AI 도슨트(`docent/`)와 나란히 `artbridge/` 폴더로 별도 관리한다. 명령은 `artbridge/`에서 실행한다.
- 새 파일과 생성물은 `artbridge/` 아래에 둔다. `sources/` 또는 AI 도슨트의 기존 파일을 수정해야만 진행할 수 있는 상황이면 그 파일은 건드리지 말고 사용자에게 충돌을 알린다.
- 권리·출처·사실 정보를 확인할 수 없으면 추정하지 말고 미확인 상태를 기록한다.
- 사용자가 구현·검증을 요청한 경우에만 그 요청 범위에 필요한 가장 작은 확인을 수행하고 결과를 보고한다. 미요청 테스트나 대규모 인프라를 추가하지 않는다.
- 계획의 목표·범위·권리 조건과 충돌하는 변경은 임의로 적용하지 말고, 가능한 작업을 계속하면서 충돌과 선택지를 사용자에게 설명한다.
